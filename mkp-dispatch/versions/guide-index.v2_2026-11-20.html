How it works

There are two ways to send something. Smart capture lets Gemini pick the list. Manual capture lets you pick it. Both end up in the same place.

Smart capture · the big New Capture button
  1. Type or dictate“Pay Jim’s invoice by Friday”
  2. Gemini reads itPicks the list, title, dates, priority. Checks for an existing task.
Confident and new → files itselfA message with Undo appears for about 8 seconds.
Unsure, or looks like a duplicate → asks youThe Confirm screen. You choose, edit and send.
Manual capture · “Choose the destination yourself”
  1. Pick the businessMKP, Super Admin, CRM…
  2. Pick the typeTo-Do, Light Bulb, Follow-up…
  3. Fill the short formTitle, details, dates, files
  4. Sent, or saved to send laterOffline captures wait and retry.
⟶Activity logs every send from every device, with who-decided-what and a two-tap Undo.
Good to know

If smart routing isn’t set up, the big button skips Gemini and goes straight to the manual path. You can tell which you have: when smart routing is on, the button says Auto-routed under “New Capture”.

What’s new after an update

The first time you open Dispatch It after an update, a card lists the changes that apply to you. It shows once per update. Admins also see admin-only notes.

  1. The update

    When it came out and how many changes apply to you.

  2. Action needed

    Outlined in amber and listed first: something you need to do, like opening the new address.

  3. The other notes

    New, Improved, Fixed, Security or Removed, each with its own icon. If you missed several updates, older ones fold under “Earlier updates”.

  4. Got it

    Closes the card. It won’t come back for this update.

  5. See all updates

    Every change that applies to you, newest first. Also in Settings → Help → What’s new.

Everyone

When it files itself

A capture files itself only when all three are true: auto-filing is switched on, Gemini is at least as confident as the admin’s threshold (85% by default), and no matching open task was found. Everything else goes to the Confirm screen.

  1. Where it went

    The list and the confidence score, for example Auto-filed to Payable · 92%.

  2. Undo

    Available for about 8 seconds. It deletes the task it just created. Missed it? Undo from Activity any time.

  3. The badge in Recent

    Shows Auto 92% so you can spot auto-filed items later.

EveryoneScreen

The Confirm screen

Appears when Gemini isn’t sure, or when it finds a task that looks like the same work. Check the list, fix anything, then send.

  1. Looks like an existing task

    An open task that means the same thing, with its list, status and how similar it is.

  2. Add as update

    Posts your note as a comment on that task instead of making a copy. View opens it in ClickUp first.

  3. Confidence

    Green is 85% and up, amber 60–84%, red below 60%.

  4. Reason

    One line on why Gemini chose this list.

  5. Destination options

    ★ is the suggestion. Below it are other likely lists with their scores. Tap one to pick it.

  6. Other list…

    Search every list in ClickUp. Lists marked yours are the app’s configured destinations.

  7. Why 64%?

    Opens the score breakdown shown below.

  8. Title

    Gemini’s cleaned-up version. Edit freely. Your full original text goes in the task description.

  9. Due and start dates

    Filled from what you said, with a note like “You said ‘by Friday’”. Clear or change them.

  10. Priority

    Urgent, High, Normal, Low, or none.

  11. Send

    Names the list you picked. It reads Create new in… when a duplicate was found, so you know you’re making a second task.

Why the score is what it is

Gemini’s own score is adjusted for things it can’t see: a close second choice (−10), the list’s track record with your team, and where similar tasks already live. The note at the bottom says what auto-filing needs.

Other list…

Type part of a name (“finance”) to filter. New ClickUp lists show up here after the workspace syncs. Picking a different list than suggested is a correction, and it teaches the next suggestions.

Everyone

Duplicates: “Add as update”

Before sending, Dispatch It compares your capture with open tasks by meaning, not exact words. “Call Jim about the invoice” matches “follow up w/ Jim re: overdue payment”. If something close exists, you choose.

  1. The closest open task

    Its list, status and similarity. View task opens it. “Also similar” lists runners-up.

  2. Add as update

    Your note becomes a comment on that task. Use this when it’s the same work.

  3. Create new anyway

    When it’s different work that only sounds alike.

  4. Cancel

    Back to the form. Nothing is sent.

Follow-ups and reminders

  1. Find the task

    Type 2 or more characters of its name, or paste its ClickUp ID. It searches that business’s task lists. Required.

  2. Pick it

    Each result shows its status, so you can tell similar names apart.

  3. Follow-up note

    Posted as a comment on that task.

Everyone

Drafts, offline and retries

You shouldn’t lose a capture to a dead zone or a closed tab.

Drafts save themselves

Every form saves as you type and comes back for 7 days. Discard starts fresh. Add to Accounts never keeps a draft.

Sent

A green check, then back to Home.

Saved for later

Offline, manual captures are kept on the device and sent automatically when you’re back online. Smart capture needs a connection, so offline it hands your text to the manual picker.

Waiting to send

The banner counts what’s queued. It retries each time Home opens. Retry now tries immediately.

“It may or may not have saved this”

This means the connection dropped after the request left your phone, so it might already be in ClickUp. Check Activity before sending again. Captures in the waiting queue check for this themselves before they resend.

Activity and Undo

The shared log of everything Dispatch It did in ClickUp, from every device, kept for 180 days.

  1. Refresh

    Reloads the list. New sends can take up to a minute to appear from other devices.

  2. Scoreboard

    How often suggestions were kept, how many filed themselves, and how many were undone.

  3. Who decided

    Auto filed itself · Confirmed someone approved a suggestion · Manual picked by hand. Update means it was added to an existing task.

  4. Where and when

    The list path and time. moved by you means someone chose a different list than Gemini suggested.

  5. Undo takes two taps

    Tap Undo, then Confirm? within 4 seconds. This stops accidental undos.

  6. Undone

    Stays in the list, struck through.

Admin

Admin access

A second passcode, set on the server, that admins enter once per device in Settings → Admin.

  1. Admin passcode

    Checked with the server. A wrong one says That admin passcode didn’t work and isn’t saved.

  2. Unlock

    Turns on admin access for this device only. Lock admin on this device turns it off again. Forget passcode also removes it.

  1. Set the admin passcode Terminal · worker folder

    Use something different from the team passcode. Until it’s set, every device has admin access and Settings warns about it.

    $k = Read-Host "Admin passcode"
$k | wrangler secret put ADMIN_PASSCODE
Remove-Variable k
  2. Unlock it on your devices App · Settings → Admin

    Tap Unlock admin, enter it, then Open admin page to check.

  3. Change it when needed

    Run the same command with a new value. Admin devices lose access and say so; each admin unlocks again.

What the server blocks without it

Changing smart routing settings, Sync workspace, building the task index, turning live updates on or off, the Chat channel lookup, and making a new ClickUp connection live. Capturing, duplicates, Activity and Undo work for everyone.

Admin

One-time setup

In order. Steps 1–4 happen in a terminal and on GitHub. Steps 5–8 happen in the app. Repeat only what changes.

  1. Sign in to the right accounts Terminal

    Cloudflare must be the c1.jumpw account and GitHub c1jumpw; Vercel is c3.jumpw. The wrong account gives “Authentication error 10000” or “Permission denied”.

    wrangler whoami
  2. Store the secrets Terminal · worker folder

    CLICKUP_CLIENT_SECRET, APP_PASSCODE, ADMIN_PASSCODE and GEMINI_API_KEY. Type them with Read-Host, never paste them into chat.

    $k = Read-Host "Paste value"
$k | wrangler secret put GEMINI_API_KEY
Remove-Variable k
  3. Create the duplicate index, then deploy the server Terminal · worker folder

    The deploy output should list TASK_VECTORS and a */15 * * * * schedule.

    wrangler vectorize create dispatch-tasks --dimensions=768 --metric=cosine
wrangler deploy
  4. Publish the app GitHub + Vercel

    Push mkp-tools (keeps the repo and the old address current), then deploy to dispatch.mkcworkspace.com from the mkp-dispatch folder, signed in to Vercel as c3.jumpw. The first time, also add the DNS record at GoDaddy: CNAME dispatch → 2464471139e6a868.vercel-dns-016.com.

    npx vercel deploy --prod
  5. Connect to ClickUp App · Settings

    Approve with an account in the MKC workspace. The server refuses any other workspace. Once the admin passcode is set, the new connection waits until an admin device confirms it; on your own device that happens by itself when you land back in Settings. One connection serves every device.

  6. Sync workspace App · Settings

    Reads every Space, Folder, List, status and custom field name.

  7. Build task index App · Settings

    Turns on duplicate detection. Keep the screen open. A few thousand tasks take a few minutes, and it pauses and resumes by itself if Gemini slows it down.

  8. Turn on live updates App · Settings

    ClickUp changes then sync within seconds instead of every 15 minutes. Then share dispatch.mkcworkspace.com and the team passcode, in person or through a password manager.

Tuning smart routing

The threshold decides how sure Gemini must be before a capture files itself. Below it, people are asked. A likely duplicate is always asked, whatever the threshold.

How it learns

When someone picks a different list or undoes an auto-filed capture, that correction is saved. It lowers that list’s track record and is shown to Gemini as an example on later captures. The model itself isn’t retrained, so a correction takes effect on the very next capture.

Passcode and connection

One passcode protects the app on every device. ClickUp access lives on the server, so devices never hold it.

  1. Change the passcode

    From the worker folder. Every device then sees “passcode was rejected”. Each person taps Forget passcode on this device and enters the new one. Do this when someone leaves the team.

    $k = Read-Host "New passcode"
$k | wrangler secret put APP_PASSCODE
Remove-Variable k
  2. Change the admin passcode

    Same as above with ADMIN_PASSCODE. Only admin devices are affected; each admin unlocks again in Settings → Admin.

  3. Reconnect ClickUp

    When anyone sees “The ClickUp connection expired”, open Settings → Connect to ClickUp on any device and approve.

  4. Rotate the Gemini key

    Make a new key in Google AI Studio, store it with wrangler secret put GEMINI_API_KEY, then delete the old key in AI Studio.

Badges and terms

Auto 92%

Filed itself at that confidence.

AI 74%

In Recent: someone confirmed Gemini’s suggestion.

Confirmed 71%

In Activity: the same thing, with the score.

Manual

Destination picked by hand.

Update

Added as a comment to an existing task.

Undone

Reversed from the toast or Activity.

Capture
Anything you send: a task, idea, note, follow-up or account.
Destination
The ClickUp list a capture lands in, shown as Space › Folder › List.
Confidence
How sure the suggestion is, after adjusting Gemini’s own score with your team’s history.
Threshold
The confidence needed to file without asking. Set by admins.
Duplicate
An open task that means the same thing as your capture.
Task index
The searchable copy of open tasks used to find duplicates.
Workspace sync
Dispatch It’s map of ClickUp’s Spaces, Folders and Lists.
Live updates
ClickUp telling Dispatch It about changes as they happen.
Worker
The small Cloudflare server that holds the ClickUp connection and runs smart routing.
Admin access
A second passcode, per device, for the controls that affect everyone.
Change log
The dated history of every change, on the admin page.
What’s new
The card after an update showing only the changes for you.
Private lists
Lists whose contents are never sent to Gemini, like MKC Client Accounts.
